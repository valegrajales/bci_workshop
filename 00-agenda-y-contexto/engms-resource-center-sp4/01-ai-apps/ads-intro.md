# Create Architecture

## Activity Description

In the “Create Architecture" activity, the technical members of the deal team work on the conceptual architecture for the solution, and where possible, the implementation architecture or its key components (these implementation details will enable us to accelerate the Realize Value stage, where implementation takes place). We will include these architectures as part of the solution design presented later to the customer.

## Roles

Specialist, Technology Specialist, Cloud Solution Architect.

## Outcome

A technical architecture for the solution is built out. Although usually done as a conceptual architecture, where possible have high level production architecture or key components of that included. This will be used as part of the proposed solution, and as input to the proposed solution.

## Task

Using Microsoft reference architectures and engaging with customer and partner as appropriate (ISD if involved for implementation would of course be driving), build out the technical architecture required for the solution.

## Content & Program

Use Product/Solution documents including both Industry solution as well as Solution Areas content as needed for the customer’s business objectives.
