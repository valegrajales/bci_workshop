# WELCOME TO Elevate your AI Apps & Agents with Hackathon​
This guide provides details and instructions to help you deliver an Elevate your AI Apps & Agents with Hackathon. 

# Learn the Delivery


The **Hackathon** allows the technical members of the team to work with a CSA coach in a guided engagement to create and deploy, partly or fully, working AI agents focused on Microsoft Foundry (Foundry Agent Service and Microsoft Agent Framework), Azure App Platform and Azure Integration Services.

On average the Hackathon takes 1-4 days of effort. This can be completed as a contiguous block of time or over a longer period of time depending on customer availability.

**To deliver this engagement:**

  - Understand the value proposition of the [AI Solution Accelerators](https://github.com/microsoft/solution-accelerators) and their [Value Proposition](./ai-hackathon-value-prop.md).

  - Familiarize yourself with the training material available on the [AI Agents Community Hub](https://aka.ms/FoundryAgents) page.

  - Use the [Seismic Page](https://microsoft.seismic.com/app?ContentId=539561de-24ad-455f-8a05-dcb95fe2e2d4#/doccenter/a5266a70-9230-4c1e-a553-c5bddcb7a896/doc/%252Fdde0caec0e-9236-f21b-2991-5868e63d3984%252FdfYTZjNDRiZDMtMzEwZS1kNWZkLTNjOGEtNjliYWJjMjhmMmUw%252CPT0%253D%252CU2Vpc21pYyBQYWdl%252Flfa425c3fb-650b-4aba-a3af-3f95063dd8bb/grid/) to introduce the Microsoft Foundry agentic patterns and related Azure App Platform and Azure Integration Services to the customer and set expectations.

  - Complete the learning path on [Develop AI agents on Azure](https://learn.microsoft.com/en-us/training/paths/develop-ai-agents-on-azure/) and on [Microsoft Agent Framework](https://learn.microsoft.com/en-us/agent-framework/) to understand the key concepts and technologies involved in building AI agents. 

  - Review the official documentation for [Microsoft Foundry Agent Service](https://learn.microsoft.com/en-us/azure/foundry/agents/overview) and [Microsoft Agent Framework](https://learn.microsoft.com/en-us/agent-framework/)

  - Review the guide to [migrate from classic Assistants to Microsoft Foundry Agent Service](https://learn.microsoft.com/azure/foundry/how-to/navigate-from-classic). The Azure OpenAI Assistants API retired on 26 August 2026; do not use Assistants-based content in this engagement.

  - Familiarize yourself with the [MCP tooling for AI Agents](https://devblogs.microsoft.com/dotnet/build-mcp-remote-servers-with-azure-functions/)

  - Learn about [Agent2Agent (A2A) protocol](https://www.microsoft.com/en-us/microsoft-cloud/blog/2025/05/07/empowering-multi-agent-apps-with-the-open-agent2agent-a2a-protocol/?msockid=37a56495fd6b69ee28087172fcb268d9)

  - Review the [Workflows with AI agents and models in Azure Logic Apps](https://learn.microsoft.com/en-gb/azure/logic-apps/agent-workflows-concepts)

  - Learn about [Use Azure Managed Redis as a semantic cache](https://learn.microsoft.com/en-us/azure/redis/tutorial-semantic-cache)

  - Review the  [MCP support in Azure API Management (APIM) to expose a REST API as a remote Model Context Protocol (MCP) server](https://learn.microsoft.com/en-us/azure/api-management/export-rest-mcp-server).
