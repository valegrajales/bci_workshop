# Workshop - Develop AI Apps and Agents on Azure

This workshop is designed to enable developers to build production-ready AI applications and intelligent agents using Microsoft Foundry and Azure AI services. The course focuses on developing generative AI solutions, implementing RAG pipelines, integrating multimodal capabilities, and orchestrating autonomous agents with enterprise-ready governance.

Participants will gain exposure to end-to-end AI solution development, including model evaluation, prompt optimization, knowledge grounding, and responsible AI practices, enabling them to design scalable and intelligent agentic workflows aligned with modern enterprise AI architectures.

## Objectives and Outcomes

**Objectives**

By the end of this Workshop, participants will be able to:

-	Build generative AI applications using Microsoft Foundry with prompt engineering and RAG pipelines.

-	Develop AI agents integrating tools, memory, and orchestration capabilities.

-	Implement multimodal AI solutions including vision, speech, and document intelligence. 

-	Design AI-powered workflows integrating external knowledge sources and enterprise systems. 

-	Apply responsible AI practices and governance in solution development.


**Outcomes**

 Upon successful completion of this Workshop, Participants will be able to:

-	Design and deploy AI applications leveraging Foundry SDK and Azure AI services.
  
-	Implement agent-based architectures with multi-agent orchestration.
  
-	Develop end-to-end pipelines for knowledge grounding and information extraction.
  
-	Demonstrate AI solutions combining language, speech, vision, and document processing.
  
-	Validate solutions with production readiness, scalability, and governance considerations.
