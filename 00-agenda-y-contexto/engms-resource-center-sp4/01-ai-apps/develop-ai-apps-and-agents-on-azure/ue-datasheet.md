# Workshop - Develop AI Apps and Agents on Azure

Workshop | 2 Days | Remote | Onsite | 300 - Advanced

## Description
This workshop provides a comprehensive learning experience for building production-ready AI applications and intelligent agents using Microsoft Azure. It focuses on leveraging Microsoft Foundry to develop generative AI solutions, implement Retrieval-Augmented Generation (RAG) pipelines, and design autonomous agents with multi-agent orchestration. Participants will also explore multimodal AI capabilities, including vision, speech, and language processing, while integrating knowledge sources and external systems into intelligent workflows.

## Objectives

By the end of this course, participants will be able to:

-	Build generative AI applications using Microsoft Foundry with prompt engineering and optimization techniques .

-	Develop intelligent AI agents with tool integration, memory, and orchestration capabilities..

-	Implement multimodal solutions covering text, speech, vision, and document intelligence. 

-	Design knowledge grounding pipelines using Azure AI Search and content extraction services.. 

-	Apply responsible AI practices and governance in AI solution development.. 


## Outcomes

Upon successful completion of this course, participants will be able to:

-	Participants will be able to design and deploy enterprise-grade generative AI applications using Azure AI services.
-	Participants will gain hands-on experience building and orchestrating AI agents for real-world workflows.
-	Participants will demonstrate the ability to implement multimodal AI solutions across speech, language, and vision workloads.
-	Participants will validate knowledge integration pipelines connecting external data sources into AI solutions.


## Agenda
- Introduction to Azure AI, model evaluation, Foundry SDK development, RAG optimization, and responsible AI implementation.
- AI agent development, tool integration, MCP connectivity, agent workflows, and multi-agent orchestration.
- Language solutions including text analysis, speech-enabled apps, translation, and conversational agents.
- Vision and multimodal solutions including image/video processing, content understanding, and knowledge mining pipelines.
- Labs and knowledge checks are integrated across all modules to reinforce hands-on learning and solution validation. 


## Participants
- Software Developers / Application Developers / Cloud Developers working with AI-driven solutions
- Azure AI Engineers / Solution Architects


## Prerequisites
- Basic Python knowledge  
- Experience with REST APIs and SDK-based development
- Access to Azure subscriptions for instructors and participants.
- Familiarity with Azure services and Azure portal.
- Basic understanding of AI/ML concepts and inferencing workflows.

## Scope
Build Azure AI applications and agents using Microsoft Foundry, generative AI, RAG, multi-agent orchestration, and multimodal AI to deliver production-ready workflows integrated with knowledge sources for real-world scenarios.
