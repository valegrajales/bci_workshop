# Welcome to GitHub Advanced Security Foundations
Enable customers to gain practical experience and knowledge around using GitHub Advanced Security to secure code and applications.

With the speed of software development continuously increasing it is very important that we can provide customers with the piece of mind that their code and dependencies are secure. 
GitHub Advanced Security helps customers improve their security posture and makes it easier to run a mature DevSecOps practice.

This scenario is focused on the offering’s adoption across different platforms.
