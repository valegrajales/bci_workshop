# WELCOME TO Workshop - GitHub Advanced Security for GitHub Enterprise - Getting Started - Learning Path

# Learn the Delivery

This **Workshop** engagement is designed to help educate and build a digital capability in the customer's organization around GitHub Advanced Security for GitHub Enterprise.
The knowledge customers need to achieve success with the adoption, operation, and governance of the offering is covered by this workshop.

The various parts of this engagement can be delivered as 1-day engagements. Check the **[Delivery Guide](./ghas-deliveryguide.md)** for more details. Several parts of the engagement can also be delivered together as a longer engagement.
When scheduling it is recommended to adjust to the needs and requirements of the customer considering the availability of all stakeholders.

To deliver this engagement:

 - Review the **[Delivery Guide](./ghas-deliveryguide.md)** - The delivery guide provides guidance and resources to support you during the delivery  

 - **Review the Delivery Standards** - Ensure that you provide the cusotmer with all deliverables as outlined in the delivery guide.
