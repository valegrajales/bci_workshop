# Complete Go-Live Assessment for Migrating Code Repositories to GitHub

## Activity Description

Once the end of implementation is achieved, to reach hand over status, an assessment of the technical and operational decision points is required. If the decision is “no”, identification and execution of any additional work is required before handing over to the customer and/or applicable party.

### Migrations specific Assessment-specific context
The customer is guided through an assessment to assess their current state and capabilities. The "Go"/"No-Go" decision point indicates if the customer has the relevant capabilities to successfully build and run modern applications on cloud platforms.  
The assessment helps evaluate both organizational and team specific areas of improvement and determines key areas of potential learning and development. 
 
## Roles

Cloud Solution Architect, Cloud Solution Architect Developer Advocate, Specialist
 
## Outcome

Implemented solution is either given go live decision, or else further work is looked at to mitigate any outstanding issues preventing this. 


## Task

Work through all technical and operational checks to ascertain if a go decision can be achieved or not, and if not identify what additional work is required to get to a go decision.
 
## Content & Program

Leverage Product/Solution documents including both Industry solution as well as Solution Areas content to deploy in a way that helps realize value for the customer’s business.
