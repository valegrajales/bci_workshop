# Oversight of MVP to production deployment

## Activity Description​

During the Oversight of MVP to production deployment activity, if an MVP or pilot was created as part of the opportunity, it may need to be moved or expanded to production or removed altogether. 
 
## Roles 

Cloud Solution Architect (ISD, partner as per situation).
 
## Outcomes

If an MVP or Pilot was in place, it has been moved/expanded to production as part of the production solution.
 
## Tasks

Engage in technical work to expand or move MVP or Pilot environments into production as applicable.
 
## Content & Programs

Leverage Customer Success Plan, Product/Solution Assets, Deployment Guide (Landing Execution Playbook), MIP to deploy in a way that helps realize value for the customer’s business
