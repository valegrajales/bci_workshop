# WELCOME TO GitHub Copilot - Zero to Agents Immersion - Learning Path

 - **Prepare Demonstration Environment**
   - Set up access to GitHub Copilot Enterprise features
   - Install VS Code with GitHub Copilot extension
   - Configure sample repositories and agent configurations for demonstration purposes
   - Review agent mode demonstrations and MCP examples
   - Customize demo scenarios based on customer interests identified during scoping

 - **Join the [Delivery Community](https://teams.microsoft.com/l/channel/19%3A2da84a09114b46449ca0278bf8354738%40thread.tacv2/VBD%20-%20Copilot%20for%20Developers?groupId=591c20e8-6a02-4476-8881-849bf672e6cf&tenantId=72f988bf-86f1-41af-91ab-2d7cd011db47)** on Teams
   - This community is used to get help, share best practices, provide feedback to improve this engagement and learn about upcoming changes

 - **Review the Delivery Standards** 
   - Deliver comprehensive demonstrations of GitHub Copilot Agents capabilities and agentic workflows
   - Provide interactive exploration sessions with Q&A to address team-specific scenarios
   - Share best practices and practical guidance for implementing agent-driven development
   - Deliver a summary presentation covering key concepts, use cases explored, and recommended next steps
   - Be prepared for follow-up discussions to help the customer plan their Copilot Agents adoption journey. Each workshop delivery is unique and may require different next steps based on the customer's context and interests.

 - **Suggested Certifications and Training** 
   - GH-900 (GitHub Fundamentals)
   - GH-300 (GitHub Copilot)
   - Practical Developer experience with GitHub Copilot and AI-assisted coding

 - **Accreditation**
   - Complete the accreditation assessment to validate your knowledge of GitHub Copilot Agents and readiness to deliver this immersion engagement. The assessment covers key concepts, demonstration scenarios, and best practices for implementing agentic workflows with GitHub Copilot.
