# SQL Chatter (With GitHub Copilot & Azure OpenAI)

Please use the repo [`https://github.com/241/ghcopilotdemo/`](https://github.com/241/ghcopilotdemo/) to access the hackathon. The hackathon activity contains instructions on how to build a natural language-based SQL chat application using GitHub Copilot as well as an application template that leverages OpenAI and that participants can deploy to try the functionality before/after the exercise to experience the desired functionality.

Please use the link [`Use Case Steps`](https://241.github.io/ghcopilotdemo/) to directly access the guide documentation for both exercises in the hackathon activity.
