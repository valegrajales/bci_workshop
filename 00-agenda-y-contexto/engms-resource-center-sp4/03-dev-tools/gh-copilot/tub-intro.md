# Technical Update Briefing (TUB)

## Activity Description​

Provide monthly updates on GitHub Copilot, both big and small.
 
## Roles 

Cloud Solution Architect, Specialist, Account Technology Strategist, Training Program Manager.
 
## Outcomes

Continued customer adoption and engagement with GitHub Copilot.  
 
## Tasks

Review monthly content (PowerPoint deck) prior to presenting to customer.
 
## Content & Programs

Leverage Customer Success Plan, Product/Solution Assets, Deployment Guide (Landing Execution Playbook), MIP to deploy in a way that helps realize value for the customer’s business.
