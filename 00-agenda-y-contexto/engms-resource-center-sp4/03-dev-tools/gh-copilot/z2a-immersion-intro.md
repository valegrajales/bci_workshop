

### Welcome to "GitHub Copilot - Zero to Agents Immersion"

This 1-day immersion engagement is designed to help development and non-development teams already using GitHub Copilot discover and explore the full potential of **GitHub Copilot Agents** and agentic workflows. Through expert-led demonstrations, interactive exploration, and practical use cases, participants will gain foundational knowledge and actionable insights to begin their journey toward automating complex development and non-development tasks with AI agents.

This immersion showcases advanced capabilities available in **GitHub Copilot Enterprise**, including agent mode, Model Context Protocol (MCP), and custom agent development, helping teams understand how to leverage these features for maximum productivity gains.

## Roles

Cloud Solution Architect
 
## Outcomes

After this immersion, participants will:

- Understand GitHub Copilot Agents capabilities and how they differ from traditional Copilot features
- Gain insights into Model Context Protocol (MCP) architecture and extensibility patterns
- Explore real-world automation scenarios using agentic workflows
- Identify high-impact use cases for agents within their development and non-development context
- Receive a roadmap for implementing and scaling agent adoption in their organization
 
## Tasks

- Showcase advanced GitHub Copilot Agents capabilities through live demonstrations
- Provide deep-dive technical sessions on MCP and agent architecture
- Enable interactive exploration of customer-specific scenarios and use cases
- Share best practices for implementing agent-driven development and non-development workflows
- Identify opportunities for extending agentic capabilities within the customer's environment
- Deliver recommendations and next steps for beginning the Copilot Agents journey
