# WELCOME TO Accelerate your development with GitHub Copilot Hackathon - Learning Path

# Learn the Delivery

**Accelerate your development with GitHub Copilot Hackathon** is focused on showcasing GitHub Copilot value in a collaborative environment. Hackathon will help create momentum in your GitHub Copilot adoption journey by allowing your developers to experience first-hand how GitHub Copilot can be leveraged to solve various use cases relevant to their daily work, all while collaborating within and across teams.

On average this engagement takes **2 days of effort**. 
This can be completed as a contiguous block of time or over a longer period of time depending on customer availability.

To deliver this engagement:

 - Review the **[Delivery Guide](hackathon-DG.md)** 
   - The delivery guide provides guidance and resources to support you during the delivery  

 - Review the **[LevelUp workshop for this VBD](https://microsoft.sharepoint.com/teams/LevelUpSkilling/FY25%20LevelUps/Forms/AllItems.aspx?id=%2Fteams%2FLevelUpSkilling%2FFY25%20LevelUps%2FFY25%20Digital%20%26%20App%20Innovation%2FGitHub%20Copilot%20Hackathon%20%26%20Solution%20Optimization%20VBD%20Bootcamp%20%2D%20Oct%2017&p=true&ga=1)** 
   - This workshop goes over how to deliver this VBD as well as some learnings from previous customer deliveries

 - **Join the [Delivery Community](https://teams.microsoft.com/l/channel/19%3A2da84a09114b46449ca0278bf8354738%40thread.tacv2/VBD%20-%20Copilot%20for%20Developers?groupId=591c20e8-6a02-4476-8881-849bf672e6cf&tenantId=72f988bf-86f1-41af-91ab-2d7cd011db47)** on Teams
   - This community is used to get help, share best practices, provide feedback to improve this engagement and learn about upcoming changes.

 - **Review the Delivery Standards** 
   - At completion of the delivery, ensure the customer expectation and initial scope set is met.
