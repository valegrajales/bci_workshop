

### Welcome to "Accelerate your development with GitHub Copilot Hackathon"

This hackathon engagement is focused on showcasing GitHub Copilot value in a collaborative environment. Hosting the hackathon will help create momentum in your GitHub Copilot adoption journey by allowing your developers to experience first-hand how GitHub Copilot can be leveraged to solve various use cases relevant to their daily work, all while collaborating within and across teams.

## Roles

Specialist, Technical Specialist, Cloud Solution Architect, Account Technology Strategist
 
## Outcomes

This Hackathon will position your team to:

Leverage GitHub Copilot to improve their development workflow
Get hands-on experience using GitHub Copilot to solve use cases relevant to their daily work
Shorten the time between idea and production using GitHub Copilot
 
## Tasks

- Create momentum and excitement around their GitHub Copilot adoption
- Enhance internal competencies of GitHub Copilot features
- Showcase how GitHub Copilot can help improve the developer workflow in real scenarios
