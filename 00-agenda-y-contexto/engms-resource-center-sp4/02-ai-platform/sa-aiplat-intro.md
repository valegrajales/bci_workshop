# Solution Accelerator for Microsoft Foundry

## Activity Description

Landing Zone Accelerators provide architectural guidance, reference architecture and reference implementations packaged to deploy workloads on Azure at scale and aligned with industry-proven practices. Leveraging Landing Zone Accelerators helps customers deploy their Azure workloads to production faster and with fewer issues. Examples include AKS, App Service, APIM and ARO.
 
## Roles

Specialist, Technology Specialist, Cloud Solution Architect.
 
## Outcome

Landing Zone Accelerator Landing Zone Accelerator is an architecture approach and reference implementation that enables effective construction and operationalization of landing zones on Azure, at scale and aligned with Azure Roadmap and Microsoft Cloud Adoption Framework for Azure.
 
## Task

Using Microsoft reference architectures and engaging with customer and partner as appropriate (ISD if involved for implementation would of course be driving), build out the technical architecture required for the solution.
 
## Content & Program

Use Product/Solution documents including both Industry solution as well as Solution Areas content as needed for the customer’s business objectives.
