# Workshop - Foundry and Copilot Studio Agents with Microsoft Agent Factory

WorkshopPLUS | 1 Day | Remote / Onsite | 300 - Advanced

## Description

This workshop is designed to help teams build enterprise‑grade copilots by integrating Microsoft Copilot Studio with Azure AI services. Through presentations and guided labs, participants learn how to design, configure, and deploy copilots that use Azure AI Search, Azure AI Foundry models, enterprise data sources, and secure orchestration patterns with practical execution and theory, enabling attendees to progress from concept to functional prototypes using real integrations and end‑to‑end scenarios.

## Objectives

This VBD allows participants to gain practical, hands-on experience building intelligent agents through guided labs.
- Gain practical experience integrating Copilot Studio with Azure AI services through step‑by‑step guided labs.
- Build and configure RAG‑enabled copilots using Azure AI Search, vector indexes, custom embeddings, and Azure AI Foundry models.
- Learn hands‑on how to implement and deploy enterprise design decisions including authentication, environment strategy, governance, data security boundaries, and monitoring.

## Outcomes

After attending the sessions, participants will gain:
- Hands-on experience connected to Azure AI Search, Azure AI Foundry, and enterprise data sources through hands‑on lab exercises.
- Knowledge of Copilot Studio + Azure AI integration patterns, including RAG workflows, actions, and extensions.
- Clear implementation guidance for operationalizing these solutions in production environments including governance, lifecycle management, and optimization.
- Reusable lab materials, scripts, and templates to replicate or extend the integrations within customer projects.
