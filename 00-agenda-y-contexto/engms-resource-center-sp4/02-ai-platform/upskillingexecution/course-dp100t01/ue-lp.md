## Recommended learning

### Azure Machine Learning – Recommended Learning Resources

#### 🔹 Overview & Capabilities

- https://learn.microsoft.com/en-us/shows/ai-show/whats-new-with-azure-machine-learning  
  Discover the latest features including drag-and-drop ML, AutoML UI, MLOps, Azure Data Factory integration, and Power BI visualization.

- [**Azure Machine Learning Studio Overview**](https://learn.microsoft.com/en-us/shows/ai-show/azure-machine-learning-studio)  
  A guided tour of the immersive web experience for managing the ML lifecycle, from no-code to code-first workflows.

---

#### 🔹 Data Access & Integration

- https://learn.microsoft.com/en-us/azure/machine-learning/how-to-access-data  
  Learn how to securely connect to Azure storage services using datastores for ML workflows.

- https://learn.microsoft.com/en-us/javascript/api/overview/azure/machinelearning  
  Documentation and packages for using Azure ML with JavaScript, including GitHub links and SDK references.

---

#### 🔹 Platform Comparison & Concepts

- https://learn.microsoft.com/en-us/azure/machine-learning/concept-azure-ai-foundry-vs-studio  
  Compare the two experiences, including LLMOps, prompt flow, and Responsible AI dashboards.

- https://learn.microsoft.com/en-us/azure/machine-learning/concept-glossary  
  A dictionary of key terms and components used in Azure ML, including datastores, components, and data types.

---

#### 🔹 Model Management & Deployment

- [**MLOps with Azure Machine Learning**](https://learn.microsoft.com/en-us/azure/machine-learning/concept-model-management-and-deployment?view=azureml-api-2)  
  Learn how to manage the ML lifecycle using Azure Pipelines, Git integration, and CI/CD for model deployment.

- [**Deploy models for scoring in batch endpoints**](https://learn.microsoft.com/en-us/azure/machine-learning/how-to-use-batch-model-deployments?view=azureml-api-2&tabs=cli)  
  Guide to deploying models for real-time and batch inference using Azure ML endpoints.

---

#### 🔹 Deep Learning & AI

- [**Deep Learning vs. Machine Learning**](https://learn.microsoft.com/en-us/azure/machine-learning/concept-deep-learning-vs-machine-learning?view=azureml-api-2)  
  Understand the differences between deep learning and traditional ML, and how to implement both in Azure ML.

---
