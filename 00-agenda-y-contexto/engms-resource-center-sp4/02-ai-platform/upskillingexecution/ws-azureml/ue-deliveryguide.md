# WorkshopPLUS - Azure Machine Learning

This three-day WorkshopPLUS course provides participants with a comprehensive understanding of Azure Machine Learning (Azure ML), covering both foundational and advanced topics. The workshop is structured to deliver hands-on experience through modular lessons and labs aligned with real-world scenarios.

## Objectives and Outcomes

**Objectives**

- Understand the basics of Machine Learning and Data science concepts - including Regression, Classification, Time Series Analysis and Clustering
- Optimizing Data for Better Insights
    - Describe variables and summary statistics, explore data, visualize data, and perform univariate and bivariate data analysis
    - Remove duplicates and unrelated observations, treat missing values, treat outliers, and perform feature engineering
    - Understand and avoid over-fitting and under-fitting, and apply model improvement techniques
- Azure Machine Learning Service
    - Introduction to Azure Machine learning service
    - Understand anbd test Azure Machine Learning Model Training and Deployment
    - Understand and deploy Azure Machine Learning Pipelines 
- Azure Machine Learning Service - Advanced Topics
    - Understand Responsible AI concepts 
    - Understand Machine Learning Operations concepts
    - Understand options for Generative AI implementation in Azure Machine Learning Service
    - Understand monitoring and best practices in Azure Machine Learning Service

**Outcomes**

- Apply foundational and advanced machine learning techniques—including regression, classification, clustering, and time series analysis—to real-world business scenarios.
- Perform effective data preparation by cleaning datasets, handling missing values and outliers, and enhancing model performance through feature engineering and regularization.
- Utilize Azure Machine Learning Service to build, train, deploy, and manage machine learning models, and orchestrate workflows using pipelines.
- Implement advanced Azure ML capabilities such as Responsible AI, MLOps practices, monitoring strategies, and Generative AI integration, following industry and platform best practices.
