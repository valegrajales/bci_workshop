# CSA Pre-Engagement Checklist (Internal)

## Customer & business context
- [ ] Business objectives and success criteria documented
- [ ] Target users/personas and primary channels identified

## AI Immersion Workshop validation
- [ ] Confirm if AI Immersion Workshop was conducted
- [ ] Review outcomes (use cases, value hypotheses, prioritized scenarios, constraints)

## Scenario intake
- [ ] Initial scenario list collected (names + goals + users)
- [ ] Initial prioritization hypothesis (value/feasibility/effort)

## Technical readiness (high level)
- [ ] Microsoft 365 baseline (Teams, SharePoint, M365 Copilot surfaces)
- [ ] AI platform readiness (Copilot Studio, Azure AI Foundry, Agent SDK/SK)
- [ ] Data/knowledge sources identified and classified
- [ ] Integration targets identified (systems/APIs)

## Governance & constraints
- [ ] Security/compliance expectations captured
- [ ] Identity model (Entra ID) and access constraints noted
- [ ] Logging/observability expectations captured

## Engagement logistics
- [ ] Stakeholders confirmed (Biz owner, Architect, Security, Eng lead)
- [ ] Scope and out-of-scope confirmed
- [ ] Workshop agenda and cadence confirmed
