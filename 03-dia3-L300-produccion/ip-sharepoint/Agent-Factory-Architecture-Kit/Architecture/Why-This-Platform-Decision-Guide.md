# “Why This Platform?” — Decision Guide (One-Pager)

Use this guide to keep recommendations explainable, consistent, and defensible.

## Microsoft Copilot Studio
**Best for:** rapid agent experiences, low-code orchestration, Teams/M365 integration, governed publishing.
**Avoid when:** deep custom runtime control is required or complex agent frameworks are mandatory.
**Notes:** pair with enterprise knowledge sources and approved integrations.

## Azure AI Foundry
**Best for:** model selection, prompt & safety workflows, evaluation, and AI service orchestration.
**Avoid when:** requirement is purely M365 surface customization without Azure AI needs.

## Microsoft 365 Agent SDK
**Best for:** pro-code agent logic, extensible orchestration, custom tools, deeper integration patterns.
**Avoid when:** low-code delivery and rapid iteration is primary.

## Semantic Kernel
**Best for:** orchestration patterns, tool calling, memory, and multi-agent coordination in code.
**Avoid when:** governance and managed publishing is required without custom build.

## Teams AI Library
**Best for:** Teams-first experiences and conversational UX patterns in Teams.
**Avoid when:** channel is not Teams and Teams-specific UX isn’t required.

## Azure Bot Service / Agent Framework
**Best for:** traditional bot channels and broader bot hosting patterns.
**Avoid when:** primary need is modern agentic orchestration in Copilot/M365 surfaces.
