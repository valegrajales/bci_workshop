# Architecture Review Checklist (Internal)

## Component completeness
- [ ] UI / surfaces defined
- [ ] Orchestration approach defined (single / multi-agent / workflows)
- [ ] Knowledge/grounding approach defined (sources, freshness, permissions)
- [ ] Integration approach defined (APIs, plugins, auth)
- [ ] Governance controls defined (identity, logging, policy)

## Platform alignment
- [ ] Recommended platforms mapped per component
- [ ] Rationale documented (why this platform)
- [ ] Trade-offs and alternatives captured

## Enterprise readiness
- [ ] Identity model (Entra) and least privilege validated
- [ ] Data sensitivity and compliance constraints addressed
- [ ] Observability/logging requirements captured

## Delivery readiness
- [ ] PoC scope and sequencing defined
- [ ] Dependencies and prerequisites captured
- [ ] Risks, assumptions, and decision log updated
