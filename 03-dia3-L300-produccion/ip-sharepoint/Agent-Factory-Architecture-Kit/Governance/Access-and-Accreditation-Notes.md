# Governance & Accreditation Notes (Internal)

## Access model for VBD content
Some VBD content is governed by solution-area security groups. By default, only members of the relevant solution area may have access to the content.

## Accreditation expectation
Where required, CSAs should review content, practice delivery, pass the Knowledge Measure (KM), and apply for accreditation prior to delivery.

## Exceptions
If a CSA outside the solution area requires access, follow the documented exception and approval process for manual access grants.
