# AI Agent Solutioning (VBD) — CSA Enablement Kit (v1)

## What this kit is
A complete, reusable set of delivery assets for Customer Success Architects (CSAs) to deliver the **AI Agent Solutioning Workshop** as an **Architecture Services / Value Based Delivery (VBD)** engagement.

## Who this is for
- CSAs delivering AI agent solutioning engagements (1–3 days)
- Account teams supporting scenario intake and stakeholder alignment
- Customer architects / engineering leads participating in workshops

## Engagement intent (summary)
This engagement helps teams evaluate AI agent use cases, decompose them into standard components (UI, orchestration, knowledge, integration, governance), map each component to the best-fit Microsoft platform, and produce a practical PoC → production pathway.

## How to use this kit (recommended flow)
1. **Prepare** — Use the pre-engagement checklist and customer intake questionnaire to collect inputs.
2. **Kickoff** — Use the kickoff deck + talk track to align scope, outcomes, roles, and cadence.
3. **Workshop** — Use the decomposition worksheet + platform mapping matrix to drive structured solutioning.
4. **Architecture** — Use the architecture review checklist + “why this platform” guide to finalize recommendations.
5. **Closeout** — Use the output summary + handoff template to enable next-phase PoC/implementation.

## Folder map
- `DeliveryGuide/` — Delivery guide and engagement definition
- `Prepare/` — Pre-work assets and customer intake
- `Kickoff/` — Kickoff deck + talk track
- `Workshop/` — Worksheets for scenario decomposition & platform mapping
- `Architecture/` — Review checklist, rationale, stencils
- `PostEngagement/` — Summary, handoff, next steps
- `Governance/` — Access & accreditation notes (internal)

## Publishing & contribution model (optional)
If you publish these assets to an engineering hub / inner-source repo, prefer Markdown for datasheets and delivery guides, and treat these templates as the baseline for contributions.
